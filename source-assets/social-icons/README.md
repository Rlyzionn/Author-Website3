# Social marks

Five inline SVG marks are sourced from the pinned Simple Icons 11.15.0 package: Instagram, Goodreads, TikTok, Facebook, and YouTube.

Source pattern: https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/instagram.svg (substitute the corresponding platform filename).

The SVG paths are inlined into labeled links in index.html; no icon library or runtime CDN request is added. Each mark is hidden from assistive technology because the adjacent platform label supplies the accessible name. Existing author destinations are unchanged.
